Adversarial bench

Ten test digits attacked with PGD (40 steps, L∞ budget ε in pixel units, white-box gradients from the chosen model). Every pixel moves by at most ε, yet the standard CNN's prediction flips.

Models

Both CNNs share one architecture: two conv-conv-pool blocks and a 128-unit hidden layer, about 0.47M parameters. The robust one was trained on PGD adversarial examples (5 steps, ε = 0.3; Madry et al., 2018).

In the browser

BatchNorm is folded into the convolutions, weights are stored as float16, and the forward pass is about 100 lines of JavaScript (digitnet.js). The attacked images were generated in PyTorch and stored as 8-bit images.

Source

Training, evaluation and attack code: GitHub repository. Numbers come from the held-out 10,000-image MNIST test set.
